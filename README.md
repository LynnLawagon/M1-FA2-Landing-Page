# FreshSense Landing Page

A responsive, editorial-style landing page for FreshSense.

## Run locally
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.
4. Keep the `img` folder beside `index.html`; the page uses those local images.

## Files
- `index.html` — page structure and content
- `styles.css` — layout, responsive styles, and light/dark themes
- `script.js` — theme switch, mobile navigation, and current year
- `img/` — supplied project images

## Notes
- The contact button currently uses a placeholder email address (`hello@freshsense.example`). Replace it with the real FreshSense contact email before publishing.
- Google Fonts are loaded online. If unavailable, the page falls back to system fonts.
- FreshSense product capabilities and performance claims should be verified before public release. The page describes odor monitoring as an aid and does not present it as a confirmed diagnosis of contamination.
